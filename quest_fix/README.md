# Квест «Гарри Поттер» — сайт записи (музей «Экспериментарий», Анапа)

Продающий лендинг с работающей системой записи: форма отправляет заявку на сервер, данные
сохраняются в PostgreSQL, администратор видит их в панели `/admin` и выгружает в Excel.

## Стек

- **Next.js 16 (App Router) + TypeScript** — фронтенд и серверные API-маршруты.
- **PostgreSQL + Drizzle ORM** — постоянное хранение заявок.
- **ExcelJS** — формирование настоящего файла `.xlsx`.
- **Tailwind CSS 4** — адаптивная вёрстка, тёмная «хогвартская» палитра.

> Проект развёртывается на платформе, где серверный код выполняется как Next.js API-маршруты
> (аналог Flask-бэкенда). Логика разделена так же: клиент → API → PostgreSQL → Excel.

## Что на сайте

1. Первый экран с фотографией музея, названием квеста и кнопкой записи.
2. Блок «О квесте» — что именно делает ребёнок.
3. Условия: возраст 8–10 лет, от 6 участников, 1 час, 1000 ₽ за ребёнка, время начала выбирается в диапазоне 10:00–15:00.
4. Фотографии музея загружаются с официального сайта.
5. Форма записи с автоматическим расчётом суммы.
6. Контакты музея и неприметная иконка входа для администратора (левый нижний угол).

## Запуск на Windows (локально)

Самый простой способ — установить **Node.js 20+** и **Docker Desktop**, затем дважды нажать `start-local.bat`.
Скрипт сам создаст локальные настройки, запустит PostgreSQL, установит зависимости, создаст таблицу заявок и откроет Next.js.

- Главная: http://localhost:3000
- Админ-панель: http://localhost:3000/admin
- Логин: `ExperementariumAdmin`
- Пароль: `ExperementariumQuestGaggyPotter`

Для работы `start-local.bat` Docker Desktop должен быть запущен. Данные PostgreSQL сохраняются в Docker volume `quest_postgres_data` и переживают перезапуск компьютера/контейнера. Не удаляйте volume, если хотите сохранить заявки.

Чтобы остановить базу, выполните в папке проекта `docker compose stop`. Чтобы снова запустить — `docker compose start`.

## Настройки администратора

Локальный скрипт записывает логин и пароль в игнорируемый Git файлом `.env`. Пароль не находится в исходниках и не отправляется в публичный репозиторий. Для размещения в интернете используйте `ADMIN_PASSWORD_HASH_B64` (bcrypt-хеш), `SESSION_SECRET` (случайная строка от 32 символов) и `ADMIN_USERNAME` как переменные окружения хостинга. Не публикуйте `.env`.

## Возможности панели

- список всех заявок с полной информацией (фамилия, телефон, количество детей, дата и время, сумма);
- поиск по фамилии и по телефону (без учёта форматирования);
- фильтр по статусам: Новая, В обработке, Подтверждена, Отменена, Выполнена;
- сортировка по дате получения и по дате квеста;
- изменение статуса и комментария администратора;
- удаление заявки;
- выгрузка всех заявок в Excel;
- данные не теряются при перезагрузке страницы и перезапуске сервера.

## Excel

Файл `.xlsx` формируется на сервере при каждом нажатии «Скачать Excel»:

- колонки: № заявки, дата и время получения, фамилия, телефон, количество участников,
  желаемый день, желаемое время, итоговая стоимость, статус, комментарий администратора;
- включён автофильтр, закреплена строка заголовков;
- телефон сохранён как текст (не теряются символы и нули);
- старые заявки не перезаписываются — файл всегда содержит все записи из базы.

## Размещение

Пошаговая инструкция для новичка — в файле **[DEPLOY.md](./DEPLOY.md)**.

Кратко: бесплатная база [Neon](https://neon.tech) + сайт на [Vercel](https://vercel.com).
Карта не нужна. После деплоя появится адрес вида `https://….vercel.app`.

Чтобы я выложил сайт сам, пришлите `DATABASE_URL` из Neon и токен Vercel
(https://vercel.com/account/tokens). Без них войти в ваш аккаунт нельзя.
